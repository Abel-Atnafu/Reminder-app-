# RemindMe — Todo & Calendar App

A React + Vite todo/reminder app with an integrated calendar view.

## Features

- **Todo List** — Create, edit, delete, and complete todos with priority, category, due date/time
- **Calendar** — Monthly grid with colored dot indicators (red=high, orange=medium, blue=low priority)
- **Calendar ↔ List sync** — Click any calendar day to filter the todo list to that date
- **Reminders** — Browser notifications before a todo's due time
- **Filters** — Search, filter by status, priority, and category
- **Persistence** — All data saved to localStorage

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```
